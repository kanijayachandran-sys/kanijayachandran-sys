### Core Capabilities

```text
Camera
   ↓
Real-Time Visual Understanding
   ↓
AI Navigation Agent
   ↓
Voice-Based Interaction
   ↓
Actionable Audio Guidance
```

### Features

* 🎥 Real-time camera understanding

* 🎙️ Voice-first interaction
